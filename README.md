# WebNova — Web Development and Responsive Website Design

A fully responsive front-end project created with HTML, CSS and JavaScript.

## Features
- Responsive layout for mobile, tablet and desktop
- Mobile navigation menu
- Smooth scrolling
- Service cards and responsive feature section
- Contact form with client-side validation and success message
- No external libraries or backend required

## Run on Android
You can upload this folder to GitHub and enable GitHub Pages.

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch** and select `main` / root.
5. Open the generated GitHub Pages URL.
